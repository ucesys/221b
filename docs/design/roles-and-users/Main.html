Admin

Full definition

Reads what Viewer reads and makes the namespaced changes Watson supports, in the namespaces it is bound in.

Can

  • Read every shown kind
  • Scale, restart, roll back
  • Delete a pod
  • Label and annotate
  • Roll back a Helm release

Cannot

  • Change roles or bindings
  • Cordon or drain nodes
  • Open a shell in a pod
  • Act outside bound namespaces
