Scripts Executions 1 running Configurations

A script declares the privilege it needs. A configuration supplies it, through an SSH profile for nodes or a Kubernetes service account for clusters, and RBAC decides who may use each one. A run is refused if the configuration gives less than the script declares, or more than the fleet allows. Dry runs always use read-only. Watson executes every run; Kubernetes calls pass through its proxy, which allows only the actions the script declares.
