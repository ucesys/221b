Approval

The scripts are approved code: kernel-patch v4, pg-switchover-if-primary v2. Runs of this job need no approval, per run, node or batch.
The schedule itself is a change on production: one more db-prod admin approves it once. Later edits to it, or a run-time value change, go through the same approval.
When v5 is approved, the job uses it from the next run. If a script is suspended by a parameter change, its runs are held until that change is approved.
