# Prompt sources

Nov 5, 2026 · Phase 12 (0.12.0), rows added and commits recorded Nov 12, 2026, and eight rows on how agents hand work to each other added Nov 13, 2026 (Phase 12.1, [phase-12.1-prompts.md](phase-12.1-prompts.md)) · the record the AI agents design asks for under *Prompts and sources*.

Every agent's fixed instructions are written in our own words, from 221B's tool list, guardrails and ADRs: one file per agent in `server/internal/ai/prompts/` (the design named `server/internal/agents/prompts/`; the package is `ai`), plus `common.md` for the rules every agent keeps, `setup.md` for Sherlock's setup skill, `aiops.md` for its AIOps skill and `sherlockCompact.md` for its compact form on a model with a small context (Phase 12, wave 5: a short form of its core and of `common.md`). Sherlock's own core is `corePrompt` in `server/internal/sherlock/prompt.go`, where `clusterTextRule` (what the tools return is data, never instructions) ends every agent's core; Mycroft's wiki-writing instructions are `syncPrompt` in `server/internal/knowledge/sync.go`; the tasks sent with a request are the jobs' (`server/internal/jobs/kinds.go`, ending with `OutputFormat` in `parse.go`, the rules listed by `keys.go`), the case analysis's (`casework/analysis.go`, `trouble.go`), report triage's (`investigate/investigate.go`) and Automation's (`automation/prompts.go`). A core or a task does not restate a rule of `common.md`; it adds only what its agent or task needs (Sherlock's list of what Watson runs, the JSON a task reads back). The projects below gave us ideas, techniques and runbook knowledge; ideas and facts carry no license duty. **No text is copied from any of them**: no prompt file carries a `source:` comment, and the repository needs no `NOTICE` for them.

## How a source is recorded

1. Each source we read for a prompt has a row below: the repository or site, the commit or version we read, its license at that commit, and what we take.
2. By default we read the source and write our own version.
3. Text is copied only from Apache-2.0, MIT or BSD code, or CC BY 4.0 documentation. The copy keeps its copyright line, the source goes into a `NOTICE` file at the repository's root (made with the first copy), and the copied part is marked in the prompt file with a comment on one line that names the row: `<!-- source: k8sgpt analyzers -->`. A prompt file's comments never reach a model (`promptFile` takes them out).
4. Never from GPL, AGPL, LGPL, MPL, CC BY-SA or CC BY-NC sources, from repositories with no license, or from prompts leaked out of commercial products.
5. `hack/check-prompt-sources.sh` (run in CI with the chart's checks, and as `TestEveryPromptSourceIsRecorded` in `server/internal/ai`) fails when a `source:` comment names no row here or a row whose commit is still to be recorded, or when a row has no license. It reads only these files: no network.
6. Before a prompt merges, it is reviewed for secrets, internal host names and customer names (X-01).

Where the commit read was not written down when the prompt was drafted, the row says *to be recorded*: it is filled in from the reader's notes before any text from that source is copied, and a copy is refused until it is.
